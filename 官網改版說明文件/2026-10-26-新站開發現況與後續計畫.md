### 本機（自己看）

在 Claude 終端機（PowerShell）貼：

```powershell
cd "E:\CascadeProjects\Aquasky Websit official\site"; npm run build; npm run cf:preview
```

看到 `Ready on http://127.0.0.1:8788` 之後，瀏覽器開：

- 首頁 http://127.0.0.1:8788/en 、 http://127.0.0.1:8788/zh
- 任一頁的網址跟舊站一樣，把 `https://aquaskyplus.com` 換成 `http://127.0.0.1:8788` 就是（例如 `/en/LQCOL-PLUS`、`/zh/news/INDUSTRY`、`/en/sel_unit_ps`）
- 頂上有黃色「PREVIEW」條＝預覽版（不收錄、不掛 GA）；正式版沒有。

注意：
- 第一次或換機器要先 `npm ci`，再 `npm run assets:copy`（把封存的圖片 PDF 複製進 `public/`，415 MB，只在本機）。
- 重建（`npm run build`）會把 dist 清掉，跑著的預覽伺服器會掛掉，重新 `npm run cf:preview` 即可。伺服器關不乾淨時，8788 埠會被殘留程序占住、看到舊版——重開前先把 node／workerd 程序結束掉。
- 要給客戶看，就得做 A-1 的雲端預覽網址（本機的只有自己看得到）。
